# SeaTech Supervised Engineering Projects

This section gathers all engineering projects supervised at SeaTech during the academic year 2025.

Each project includes:

* Reports and/or presentations
* Link to the student GitHub repository

---

## Chatbot Projects

### Chatbot SeaTech – Farah Ben Romdhane & Asmae Elazzouzi

* **Description**: Chatbot designed to provide quick access to SeaTech website information using a Retrieval-Augmented Generation (RAG) approach with a Streamlit interface. 
* **Tech**: Python, Streamlit, RAG
* **GitHub**: https://github.com/farah746/chatbot_seatech

---

###     Le Chat by SeaTech – Antonin Larvor

* **Description**: RAG-based chatbot using web scraping (Firecrawl), Flask backend, and web interface for SeaTech information retrieval. 
* **Tech**: Python, Flask, Firecrawl, RAG
* **GitHub**: https://github.com/antolarv/Seatech_Chatbot

---

###     Les Chats de SeaTech – Orlando, Arneodo, Pignol, De Cock

* **Description**: Multi-approach chatbot project exploring different implementations for SeaTech information systems. 
* **GitHub**: https://github.com/xXNzodu13xX/LesChats

---

###     SeaTech Chatbot – Otmane Ibbour

* **Description**: RAG-based chatbot with web interface for accessing SeaTech-related information.
