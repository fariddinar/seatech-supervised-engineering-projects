## Année

## Étudiant(s)

## Description  
Projet de déploiement d’un chatbot SeaTech sur Hugging Face basé sur une architecture RAG.  

Le système permet de centraliser les informations de SeaTech et de fournir des réponses automatiques, pertinentes et personnalisées selon le profil utilisateur (étudiant, candidat, enseignant, alumni).
